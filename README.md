# 🏨 StayWise AI — Hotel AI Assistant

An AI-powered hotel customer service and booking assistant built as a portfolio project using Python, Google Colab, Hugging Face Transformers and Gradio.

## 🎯 Project Objective

The goal of StayWise AI is to demonstrate how Generative AI can be used to automate hotel customer service while connecting AI responses with business logic.

## 🚀 V1 Features

- AI-powered hotel customer service
- Hotel FAQ responses
- Room information
- Hotel facilities information
- Booking intent detection
- Room identification
- Number of nights extraction
- Automatic price calculation
- Basic booking workflow
- Interactive chatbot interface

## 🧠 Technology

- Python
- Google Colab
- Hugging Face Transformers
- Qwen2.5-0.5B-Instruct
- Gradio
- Pandas
- Regular Expressions

## 🏗️ Architecture

Customer
↓
Chatbot
↓
AI Language Understanding
↓
Booking Intent Detection
↓
Room & Night Extraction
↓
Python Business Logic
↓
Price Calculation
↓
Booking Request

## 💡 Example

Customer:

"Book Standard for 4 nights"

StayWise AI:

Room: Standard Room

Price per night: €140

Number of nights: 4

Total: €560

The system then asks for the information required to continue the booking request.

## 📊 Business Use Case

A hotel could use this type of assistant to:

- Answer repetitive customer questions
- Provide room information
- Support booking enquiries
- Reduce customer service workload
- Capture potential booking leads
- Provide 24/7 customer assistance
